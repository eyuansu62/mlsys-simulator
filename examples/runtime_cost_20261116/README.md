# 运行域成本参数与全部观测

来源、拟合方法、限制和命令见[说明](../../docs/runtime-cost-calibration.md)，
数值与图表见[结果报告](../../docs/runtime-cost-20261116/README.md)。

- `dataset.json.gz`：全部6174条去敏观测与原始文件SHA，无损压缩，含2748训练、684主留出、1368重复、1374未使用。
- `split.json.gz`：拟合前固定的数据身份、成员和30%门槛。事后形状/进程分组，不是新盲测。
- `fit.json.gz`：首次且未重新调参的拟合、全部训练残差、参数与成员身份。
- `models.json`：模型ID到校准配置／完整实验的映射。
- `calibrations/`、`experiments/`：可直接加载的内联参数与实验。

完整原ZIP仍保留在用户本地，未修改；本仓库不上传可能带有私密环境信息的原始运行日志。
公开数据的source包含原ZIP与所有消费文件哈希，并记录重建／近似上下文、配置Graph未知实际分派、
跨进程profiler代理和KV分配状态变化。未覆盖的eager、后端、形状或并行布局会拒绝校准复用。
